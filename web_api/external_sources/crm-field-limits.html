Field Limits

Each field on an imported record may be at most 255 characters. Fields longer than this are silently truncated on import. No error or warning is returned. Trim or split long values before importing if this could affect your data.

Note: some fields have additional metadata appended during import post-processing (the exact suffix varies by field). This appended text counts toward the 255-character limit, so a value that is exactly 255 characters before import can still end up truncated after processing.
